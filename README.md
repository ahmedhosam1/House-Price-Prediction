🏠 House Price Prediction

This project predicts house prices using a Linear Regression model, with a focus on improving prediction accuracy and reducing model error through better feature selection and preprocessing.

📊 Dataset

Kaggle – House Prices Dataset

🤖 Model

Linear Regression

🧩 Features Used

GarageCars

Fireplaces

TotRmsAbvGrd

BedroomAbvGr

YearRemodAdd

YearBuilt

GrLivArea

OverallQual

TotalBsmtSF

GarageArea

📈 Model Improvement

The initial version of the model relied on limited features and showed higher prediction error.

By selecting more relevant numerical features and removing noisy columns, the model achieved a noticeable reduction in error.

Predictions became closer to actual house prices, reducing underfitting.
